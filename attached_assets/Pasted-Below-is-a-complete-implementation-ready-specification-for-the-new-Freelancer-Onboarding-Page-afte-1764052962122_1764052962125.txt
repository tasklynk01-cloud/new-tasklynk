✅ FREELANCER ONBOARDING PAGE — FULL TECHNICAL SPECIFICATION
1. PAGE LOCATION IN THE FLOW
1.	User registers → chooses “Freelancer” account.
2.	User completes personal details (name, education, experience, etc.).
3.	After submitting details → redirect to the new onboarding page: “Freelancer Skills & Competencies”.
4.	After completing the page → redirect to Email Verification.
________________________________________
✅ 2. PAGE STRUCTURE & FUNCTIONALITY
A. Sections on the Page
1. Subjects (Mandatory)
•	Freelancer must choose:
o	Minimum: 7
o	Maximum: 15
•	Multi-select checkbox interface.
•	Validation:
o	If less than 7 selected → show error.
o	If more than 15 selected → show error.
2. Software / Tools (No limit)
•	Can select unlimited options.
•	Add “Other (specify)” textbox.
3. Services / Type of Work (No limit)
•	Multi-select list.
•	Add “Other (specify)” textbox.
4. Submit Button
•	Saves the selections to the database.
•	Redirects user to Email Verification Page.
________________________________________
✅ 3. DATABASE SCHEMA ADJUSTMENTS
A. New Tables Needed
1. freelancer_subjects
Stores selectable subjects.
id (PK)
name VARCHAR(255)
status ENUM('active','inactive')
2. freelancer_software
id (PK)
name VARCHAR(255)
status ENUM('active','inactive')
3. freelancer_services
id (PK)
name VARCHAR(255)
status ENUM('active','inactive')
4. Mapping tables to store freelancer selections
freelancer_subject_map
id (PK)
freelancer_id (FK -> users.id)
subject_id (FK -> freelancer_subjects.id)
created_at
freelancer_software_map
id (PK)
freelancer_id (FK)
software_id (FK)
created_at
freelancer_services_map
id (PK)
freelancer_id (FK)
service_id (FK)
created_at
________________________________________
✅ 4. CHANGES IN EXISTING TABLES
users table
Add field:
skills_completed BOOLEAN DEFAULT 0
Manager/admin view
Add query filters to:
•	View freelancer skills from:
o	freelancer_subject_map
o	freelancer_software_map
o	freelancer_services_map
Add UI in dashboard:
•	Freelancer → Profile → “Skills & Competencies”
________________________________________
✅ 5. FRONTEND VALIDATION
Subjects
•	Block submission unless selections are between 7 and 15.
Software / Services
•	No limit, but require at least 1 selection in services.
On Successful Submit
•	Save → redirect to:
/email-verification?user=ID
